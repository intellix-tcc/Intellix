# Figuras a ampliar (legibilidade)

Checklist de correção do tamanho das figuras do TCC. Levantado a partir das
dimensões reais de cada imagem no documento "TCC entrega final": a largura útil
da página (A4, margens 3 cm/2 cm) é ≈ **453 pt (≈ 16 cm)**, e **33 das 34
imagens estão abaixo disso** — 32 a 75% (339 pt) e a Figura 23 a 28% (126 pt).
Só a Figura 34 usa a largura cheia.

> **Como ampliar (manual, no Google Docs):** a API do Docs não redimensiona
> imagem já inserida, então é na mão — clicar na figura → alça de canto (mantém
> proporção) arrastando até a margem, ou **Opções da imagem → Tamanho → Largura
> ≈ 16 cm**. Legenda acima (`Figura N – …`) e fonte abaixo (`Fonte: …`).
